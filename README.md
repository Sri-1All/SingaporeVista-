# 🇸🇬 SingaporeVista – Singapore Tourism & Travel Web Application
 
SingaporeVista is a **React-based tourism and travel web application** designed to help users explore Singapore's attractions, historical places, festivals, food, cultural heritage, and travel information through an interactive and responsive interface.
 
## ✨ Features
 
 
- 🏙️ **Explore Singapore** – Browse popular attractions, historical places, and must-visit destinations.
 
- 🛕 **Tamil Heritage** – Discover Singapore's Tamil heritage, cultural landmarks, and community.
 
- 🎉 **Festivals & Food** – Explore Singaporean festivals, traditional celebrations, and popular foods.
 
- 🎤 **Tamil Voices** – Learn about notable personalities and contributions from the Tamil community.
 
- 🗺️ **Interactive Map** – Locate and explore places using an interactive map.
 
- 🌦️ **Live Weather** – View current weather information using a weather API.
 
- 💱 **Currency Converter** – Convert currencies for travel planning.
 
- 🧳 **Trip Planner** – Organize and plan places to visit during a Singapore trip.
 
- 📱 **Responsive Design** – Optimized for desktop, tablet, and mobile screens.
 
- 🧩 **Reusable Components** – Built with reusable React components for maintainability.
 
- 🧭 **Structured Navigation** – Easy navigation across different sections of the application.

## ⚙️ Installation & Setup
 
### 1. Clone the repository
 `git clone https://github.com/Sri-1All/SingaporeVista-.git ` 
### 2. Navigate to the project folder
 `cd SingaporeVista- ` 
### 3. Install dependencies
 `npm install ` 
### 4. Start the development server
 `npm start ` 
The application will run locally at:
 `http://localhost:3000 `
